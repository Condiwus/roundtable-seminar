## ⚡ 快速研讨模式

> 不想一轮一轮聊，想一次性看完所有观点的对撞，用这个。

### 使用方式

用户说：**`快速 [议题]`** 或 **`快 [议题]`**

### 执行规则

跳过用户逐轮确认环节，AI 自动执行完整辩论循环：

```
用户给议题
  ↓
启动 + 邀 4-5 位代表（含意外视角，直接开局，不等待确认）
  ↓
第 1 轮：定义问题 → 动态发言 → 主持人总结 + ASCII 图
  ↓
第 2 轮：深化分歧 → 动态发言 → 主持人总结 + ASCII 图
  ↓
第 3 轮：底层假设 → 动态发言 → 主持人总结 + ASCII 图
  ↓
生成最终知识网络（含质量门控自检）→ 写入 org 文件
```

### 与完整模式差异

- **不等待用户"可/止/深挖"** — 自动跑 3 轮完整循环
- **代表发言可精简** — 每段 100-200 字（原 200-400）
- **3 轮后自动结束** — 除非用户中途说"继续"
- **适用场景**：通勤读、快速了解议题全貌、对比观点

## org 文件持久化（v3.0 Phase 6）

讨论结束后，将**完整讨论原文**写入 org-mode 文件：

1. 运行 `date +%Y%m%dT%H%M%S` 获取时间戳
2. 写入 `~/Documents/notes/{timestamp}--圆桌-{议题关键词}__roundtable.org`
3. org 文件结构：
   ```org
   #+title: 圆桌：{议题}
   #+date: [{日期}]
   #+filetags: :roundtable:
   * 议题与参会者
   [完整的参会者介绍，包括姓名、MBTI、核心立场、选择理由]
   * 开场：定义
   [主持人开场词 + 每位参会者的完整定义性发言，原文照录]
   * 各轮讨论记录
   ** 第 N 轮：{引导问题}
   *** 发言记录
   [本轮所有发言的完整原文，包括行动标签、全部论述、简言之]
   *** 主持人综述
   [核心争议点 + ASCII 框架图 + 下一层引导问题，原文照录]
   * 知识网络（全局）
   [完整的全局总结 + ASCII 知识网络图]
   * 开放问题
   [所有未解决的开放问题]
   ```
4. **关键要求**：每一段发言、每一个 ASCII 图、每一句主持人综述，都必须完整保留原文，禁止摘要或压缩
5. 向用户报告文件路径
