# Protocols — v3.2.1 RC

按需工具箱。没有具体触发理由就不加载对应协议；不顺序运行本文件。

[Kernel](../SKILL.md) 是唯一全局 Router。本文件只拥有协议的触发、操作和返回条件，不拥有另一套路由顺序。SEARCH、EXPERIMENT 等操作可由 Kernel 直接选择，无须先通过其他协议。

所有协议使用同一返回约定：更新了什么、当前判断或状态、关键未知、建议的下一 need；只保留有变化的字段，交回 Kernel。协议不自行连续调用其他协议。用户可见输出沿用 Kernel。

## Evidence

**Trigger**：决定性外部事实未知或有争议；关键现实 Claim 需要查证；用户要求查证；当前判断依赖时效信息。

**Do**：把不确定性压缩成一个具体证据问题，再找能回答它的资料。优先官方原文、原始研究、公司披露、本人原始讲话，其次可靠二手材料。区分资料发布日期与事件/数据发生时间。

统一证据标记如下，所有引擎引用此处，不另行定义：

| 标记 | 含义 |
|---|---|
| [A] | 一手证据：原始数据、论文、法规、披露、本人讲话 |
| [B] | 高质量二手证据：可靠媒体、研究综述、专业数据库 |
| [C] | 合理推演：基于已知事实或公开思想的推导 |
| [D] | 未验证假设或思想实验 |

这是依据类型标记，不是自动可信度排名。[A] 也可能样本不足或不适用；普通二手材料不因“二手”就归为 [C]。无法核验的材料明确保留未核验状态，不提升为已确认事实。

检查与 Claim 的相关性、适用人群与场景、时间、替代解释、来源独立性，以及证据究竟能区分什么。多人转述同一研究不算多个独立证据。只标记影响核心判断的论点。

**Return**：受检 Claim、可核查来源、支持/削弱/无区分力/混合、适用限制、判断变化。找不到资料或工具不可用时明确缺口，不把“未发现证据”当作反证。

**Stop**：下一次检索只会重复材料、不再改变判断，或当前可得资料无法回答关键问题时停止，保留未知。

## Claim Ledger

**Trigger**：先判断 State 是否已不足以可靠追踪主张。只有存在实际追踪负担，且至少符合下列一项，才考虑建立：

- 至少 3 个重要且真正竞争的 Claim；
- 多轮复杂 Reasoning 导致依据、状态或依赖关系难以追踪；
- 高风险判断需要保留关键主张与反证的审计线索；
- 已受反驳的关键 Claim 反复出现；
- 用户要求深挖，且确实需要追踪多项命题的变化。

以上不是自动触发。单纯“深挖”、三条普通观点或一次重要判断都不强制建表。默认只在 State 保留主要 Claim。

**Do**：单位是 Claim，不是人物。只登记影响最终判断的命题，按需要记录以下信息，避免空表：

| 字段 | 内容 |
|---|---|
| Claim / Scope | 命题及它适用的人群、时间或条件 |
| Status | 下表之一 |
| Support / Counter | 关键支持与反证，来源或推演性质 |
| Alternative / Falsifier | 竞争解释；什么能推翻它 |
| Implication | 它成立或失败会改变什么 |

| Status | 含义 |
|---|---|
| ACTIVE | 仍有竞争力，尚不等于事实 |
| WEAKENED | 出现反证或相对解释力下降 |
| FALSIFIED | 在记录的范围内与决定性证据冲突 |
| UNRESOLVED | 证据不足以判断 |
| DEPENDENT | 取决于明确的未定条件 |

FALSIFIED 的命题只有出现新的实质证据才能重开，并记录原因；改变命题范围应明确为修订后的命题，不能悄悄复活原说法。不得为人物发言、平衡或用户偏好重开。

**Return**：仍存活的关键 Claim、实际变化、最重要未决项及能区分它的信息。台账可内部维护，不默认完整展示。

**Stop**：追踪负担消失时停止扩展台账，将当前有效结论和已否定依据压回 State；不要求每轮重填未变化字段。

## Red Team

**Trigger**：默认要求 **Consensus + 至少一个 Risk Factor**。Consensus 指参与视角已经对核心判断明显一致，不以人数机械计数。

Risk Factor：高不可逆、高损失、证据薄弱、用户强烈先验、共享假设、结论异常便利，或可能翻转判断的重要未知。共识本身不触发。用户明确要求 Red Team 审查时，按其指定范围执行，无须人为制造共识。

**Do**：攻击当前结论的最强版本。只选最有可能击穿它的角度：最强反例、基础率、遗漏变量、选择偏差、激励、沉没成本、二阶效应、不可证伪性、事实相反时的预测、更简单解释或共享假设。不是十二项必答清单。

**Return**：最强威胁、受影响前提、能改变判断的证据及当前影响。没有发现实质威胁就如实说明。

**Stop**：反对意见开始牵强、重复，或威胁已转成明确可查证/可测试的问题时交回 Kernel。高风险但尚无共识时，仍可进行普通证据和反例检查，不强制使用本协议。

## Belief Update

**Trigger**：新证据、强反例、新机制或现实结果可能改变当前判断。

**Do**：说明“哪条新信息，为什么改变哪项判断”，使用 `↑ 强化 / ↓ 削弱 / ≈ 基本不变 / ? 未知`；幅度可用文字说明。只有可靠数据与适用模型支持时才使用精确概率。

**Return**：原判断 → 信息及理由 → 当前判断；区分信念变化与行动变化。新偏好可能改变行动而不改变事实。

**Stop**：完成这次变化记录即可；没有新信息，不生成装饰性更新链。

## Trust Calibration

**Trigger**：即将形成重要或较强结论，且证据混合、不确定性或错误代价可能导致信心失配。

**Do**：只检查最相关的依据强度、机制、基础率、反方存活情况、适用范围、私人信息与未知变量。分别校准：

- Epistemic Confidence：判断为真的信心，高 / 中 / 低 / 未知。
- Action Confidence：当前行动值得执行的信心，高 / 中 / 低 / 未知。

可逆性和错误代价影响行动信心，不能凭低成本把“为真的信心”提高。认识信心中等、行动信心高可以同时成立。

**Return**：两类信心及理由、最大威胁、什么会改变判断；不做无依据的加权评分。

**Stop**：足以表达当前限制即可，不为追求确定性反复校准。

## Decision Threshold

**Trigger**：现实选择确实依赖变量或边界条件，需要把判断转成条件化行动。明显而简单的行动无需完整决策表。

**Do**：只保留真正改变行动的少数变量，建立 `Action = f(variable)`。阈值可以是有依据的数字或可观察条件；不能确定时写 **Threshold Unknown**，并指出所缺输入。需要计算则交回 Kernel，而不是猜数。

比较有意义的行动选项的适用条件、收益、损失、可逆性与切换条件；没有合理备选就不制造 Plan B。等待也是选项，但需说明等什么、何时重看以及等待成本。

**Return**：条件 → 当前方案 → 切换条件，必要时列未知阈值。用户可见行动结构采用 Kernel 的 Action Mode。

**Stop**：选择或下一项必要信息已明确时停止；不为了覆盖所有未来情景扩展决策树。

## Reality Test

**Trigger**：Kernel 依据可逆行动原则选择 EXPERIMENT，且现实观察比继续讨论更能区分关键假设。已有充分依据的执行直接 ACT，无须把一切包装成实验。

**Do**：设计能回答当前问题的最小测试，交代假设、最小行动、可观察指标、时间窗口、成功/失败或无法判别的信号，以及什么结果会改变下一步。预先说明成本边界与如何撤回；边界依实际约束确定，不编造“标准样本量”。

便宜、快速还不够，测试应具有区分力。若混杂、样本或测量不足，结果只算未定，不宣布胜者。纯价值命题或不可重复的历史事实不强行实验。

可逆性不扩大用户授权：没有发布、发送、购买等授权时，交付可审阅方案/本地材料并明确待执行；已获授权的动作直接推进。没有工具或实测数据时，不能声称实验已完成。

反馈返回后比较预测与实际观察，区分模型错误、实施偏差和仍未知的原因，交回 Kernel 更新判断。

**Return**：可执行测试方案及预期判别标准；若已实施，再附观察结果与限制。严格区分已设计、已执行、已获得结果。

**Stop**：设计足够可执行，或当前授权范围内实施完成后停止讨论；若需等待结果，记录等待对象，不虚构反馈、不重复思辨。

## Quality Gate

**Trigger**：完成一个主要认知操作后，做一次轻量“这一轮到底改变了什么？”检查。仅在发现质量问题时展开相关项，不是再跑所有协议。

**Do**：按实际风险查看问题定义、候选遗漏、证据、反例、假分歧、噪声、收敛或行动是否受损。没有实质变化时，指出瓶颈，不再安排相同讨论。

**Return**：实质变化；或尚未解决的问题和原因。

**Stop**：回答了“有何变化/为何无变化”即结束，交回 Kernel；不额外生成质量报告。
